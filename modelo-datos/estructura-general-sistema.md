# Estructura general del sistema

## Nombre propuesto

```text
visualweb
```

## Objetivo

Documentar de manera general los módulos que forman parte del sistema y los prefijos iniciales asociados a sus tablas.

Este documento aplica como referencia general para todo el sistema.

## Módulos

| Prefijo inicial | Módulo |
|---|---|
| `vm` | Contabilidad |
| `vs` | Comercial |
| `nn` | Propiedad horizontal |

## Alcance

- `vm` identifica las tablas pertenecientes al módulo de contabilidad.
- `vs` identifica las tablas pertenecientes al módulo comercial.
- `nn` identifica las tablas pertenecientes al módulo de propiedad horizontal.

El documento únicamente establece la relación entre los prefijos iniciales y los módulos del sistema. No define ni propone nombres de tablas.
